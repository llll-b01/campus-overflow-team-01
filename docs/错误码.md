# 业务错误码

所有错误响应遵循 RFC 9457 Problem Details，并扩展 `code` 字段：

```json
{ "type": "about:blank", "title": "Unprocessable Entity", "status": 422,
  "detail": "不能给自己的内容投票", "code": "QA-1015" }
```

## 分段约定

| 前缀 | 上下文 | 段位含义 |
| --- | --- | --- |
| `ID-` | Identity | `1xxx` 业务规则 / `2xxx` 冲突 / `3xxx` 权限 / `4xxx` 未找到 |
| `QA-` | Q&A | 同上 |
| `REP-` | Reputation | 同上 |
| `DIS-` | Discovery | 同上 |
| `AUTH-` | 认证与 CSRF | 401 / 403 / 429 |
| `SYS-` | 平台级 | 参数校验、并发冲突、未知异常 |

## HTTP 状态映射

| 领域异常 | 状态码 | 典型场景 |
| --- | --- | --- |
| `BusinessRuleException` | 422 | 违反业务规则（自投票、悬赏积分超限） |
| `ConflictException` | 409 | 状态冲突（重复采纳、悬赏已结束） |
| `ForbiddenException` | 403 | 权限不足（非提问者采纳、越权查看流水） |
| `NotFoundException` | 404 | 资源不存在或已软删除 |
| 乐观锁失败 | 409 `SYS-409-CONCURRENT` | 并发编辑同一内容 |
| 唯一约束冲突 | 409 `SYS-409-DUPLICATE` | 重复提交（如并发投票） |

## 常用错误码速查

| 错误码 | 含义 |
| --- | --- |
| `ID-1004` | 密码不满足强度要求（8–64 位，含字母与数字） |
| `ID-2001` | 学号/工号或邮箱已被注册 |
| `QA-1001` / `QA-1002` | 标题长度、问题/回答正文长度不合法 |
| `QA-1003` | 评论长度不合法（2–600 字符） |
| `QA-1004` | 标签格式不正确（仅允许中英文、数字与 `# + . - _`） |
| `QA-1005` | 标签数量必须为 1–5 个 |
| `QA-1010` | 该回答不属于当前问题 |
| `QA-1011` | 已删除的回答不能被采纳 |
| `QA-1012` | 已被采纳的回答只能由课程教师/助教删除 |
| `QA-1013` | 已有回答的问题只能由课程教师/助教删除 |
| `QA-1014` | 投票值只能是 +1 或 -1 |
| `QA-1015` | 不能给自己的内容投票 |
| `QA-1016` | 评论回复只支持一层，不能再回复二级评论 |
| `QA-1017` | 回复必须与被回复的评论挂在同一内容下 |
| `QA-1020` | 内容已删除，不能再操作 |
| `QA-2002` | 问题已采纳，不能重复采纳 |
| `QA-2003` | 该回答已被认证，不能重复认证 |
| `QA-3001` | 只有提问者或课程教师/助教可以采纳 |
| `QA-3002` | 只有作者或课程教师/助教可以编辑 |
| `QA-3003` | 只有作者或课程教师/助教可以删除 |
| `QA-3004` | 只有课程教师/助教可以认证回答 |
| `REP-1002` | 可用悬赏积分不足 |
| `REP-1003` / `REP-1004` | 悬赏积分（10–500）或期限（1–14 天）超范围 |
| `REP-3002` | 只能查看自己的声誉流水 |
| `DIS-1001` | 搜索关键词每个词项至少 2 个字符（ngram 分词粒度限制） |
| `AUTH-401` | 未登录 |
| `AUTH-403-CSRF` | 缺少或错误的 CSRF 令牌 |
| `AUTH-429` | 登录失败次数过多（1 分钟内 5 次） |

## Q&A 上下文错误码明细

> 编号以《实验指导书 V2》3.7 节为准。该节区分「已给定」（必须严格使用）与「建议」
> （Sprint 0 全组确认后写回本文档）。本上下文的建议码已于 2026-10-25 对齐，
> 对齐前后的差异见本文末「编号变更记录」。

领域层实际抛出的全部错误码与触发条件。应用层与前端据此做分支处理，
**不要靠匹配错误消息文本判断**——消息可能随文案调整而变化，`code` 才是契约。

### 1xxx 业务规则（→ 422 `BusinessRuleException`）

| 错误码 | 触发条件 | 抛出位置 |
| --- | --- | --- |
| `QA-1001` | 标题不在 10–150 字符（按 Unicode 码点计） | `Title` |
| `QA-1002` | 问题正文不在 20–30000 字符；回答正文不在 10–30000 字符 | `MarkdownBody` |
| `QA-1003` | 评论正文不在 2–600 字符（单字评论无信息量） | `Comment.post` |
| `QA-1004` | 标签为空，或不匹配 `^[\p{L}\p{N}][\p{L}\p{N}#+.\-_]{0,29}$` | `TagName` |
| `QA-1005` | 去重后标签数不在 1–5 个 | `Tags` |
| `QA-1010` | 采纳的回答 `questionId` 与当前问题不符 | `Question.accept` |
| `QA-1011` | 采纳一个已软删除的回答 | `Question.accept` |
| `QA-1012` | 回答者删除已被采纳的回答（防「先骗采纳再删除」，课程管理者不受限） | `Answer.softDelete` |
| `QA-1013` | 提问者删除 `answerCount > 0` 的问题（课程管理者不受限） | `Question.softDelete` |
| `QA-1014` | 投票值不是 +1 或 -1 | `Vote.cast`、`Vote.change` |
| `QA-1015` | 投票者与内容作者是同一人 | `Vote.cast`、`VoteService.cast` |
| `QA-1016` | 回复二级评论（只支持一层） | `Comment.post` |
| `QA-1017` | 回复与父评论的 `targetType`/`targetId` 不一致（挂错内容） | `Comment.post` |
| `QA-1020` | 对已软删除的问题/回答执行编辑、采纳、回答、评论、投票、删除 | `Question`、`Answer`、`VoteService`、`CommentService` |

### 2xxx 状态冲突（→ 409 `ConflictException`）

| 错误码 | 触发条件 | 抛出位置 |
| --- | --- | --- |
| `QA-2002` | 问题已有 `acceptedAnswerId`，再次采纳 | `Question.accept` |
| `QA-2003` | 回答已有 `endorsedBy`，再次认证 | `Answer.endorse` |

### 3xxx 权限不足（→ 403 `ForbiddenException`）

| 错误码 | 触发条件 | 抛出位置 |
| --- | --- | --- |
| `QA-3001` | 采纳者既非提问者本人，也非课程管理者 | `Question.accept` |
| `QA-3002` | 编辑者既非内容作者，也非课程管理者 | `Question.edit`、`Answer.edit` |
| `QA-3003` | 删除者既非内容作者，也非课程管理者 | `Question.softDelete`、`Answer.softDelete` |
| `QA-3004` | 认证者不是课程管理者（回答者本人亦无权认证自己的回答） | `Answer.endorse` |

### 关于「课程管理者」

3xxx 段的判据统一为 **「内容作者本人 `||` `actorManagesCourse`」**。

`actorManagesCourse` 是一个由**应用层**计算后传入领域方法的布尔值，表示
「当前操作者是否管理该问题所属的课程」。领域层不自行调用
`Actor.isTeacherOrAdmin()`——全局角色（TEACHER/ADMIN）与课程内角色
（某门课的教师/助教）是两件事，后者属于 Identity 上下文的课程成员关系，
跨上下文只能经 `*-api` 查询。

> 实现应用层时请注意：一位 `Role.TEACHER` 的用户若不教这门课，
> `actorManagesCourse` 应为 `false`，不能一律放行。

### 正文长度取值说明

| 场景 | 范围 | 依据 |
| --- | --- | --- |
| 问题正文 | 20–30000 | 上限见 `QuestionController` `@Size(max = 30000)`；下限见 `AskPage.tsx`「至少 20 字」提示与 `QuestionTest` 的 22 字边界用例 |
| 回答正文 | 10–30000 | 上限见 `AnswerController` `@Size(max = 30000)`；**下限 10 为实现时的暂定值**，领域测试中最短用例为 13 字，无下界断言 |
| 评论正文 | 2–600 | 上限见 `CommentController` `@Size(max = 600)`；下限 2 见指导书 V2 第 3.7 节（单字评论无信息量） |

> ⚠️ 回答正文下限 10 字属于产品决策，尚未经 PO 确认。若需调整，
> 改 `MarkdownBody.MIN_ANSWER` 一处即可。


### 4xxx 资源不存在（→ 404 `NotFoundException`）

| 错误码 | 触发条件 | 抛出位置 |
| --- | --- | --- |
| `QA-4001` | 问题不存在或已软删除 | `QuestionCommandService`、`QuestionQueryService`、`VoteService`、`AnswerCommandService` |
| `QA-4002` | 回答不存在或已软删除 | `AnswerCommandService`、`VoteService`、`CommentService` |
| `QA-4003` | 被回复的评论不存在 | `CommentService` |

> 「课程不存在」用 Identity 上下文的 `ID-4002`，不在 Q&A 另起编号——课程是 Identity 的资源。

## 编号变更记录

**2026-10-25｜对齐《实验指导书 V2》3.7 节**

V2 把错误码分为「已给定」（必须严格使用）与「建议」（Sprint 0 全组确认后写回本文档）。
本上下文最初实现时 V2 尚未发布，建议档的编号为自行拟定，现统一对齐。

「已给定」的 `QA-1001` / `QA-1002` / `QA-1004` / `QA-1005` / `QA-1015` / `QA-2002` / `QA-3001`
原本即与 V2 一致，未作改动。

| 场景 | 旧码 | 新码 |
| --- | --- | --- |
| 评论长度不合法 | `QA-1002` | `QA-1003`（并入独立编号，下限由 1 改为 2） |
| 投票值不是 ±1 | `QA-1006` | `QA-1014` |
| 回复二级评论 | `QA-1007` | `QA-1016` |
| 内容已删除 | `QA-1008` | `QA-1020` |
| 回答不属于当前问题 | `QA-1009` | `QA-1010` |
| 已删除的回答不能被采纳 | `QA-1008` | `QA-1011`（从通用「已删除」中拆出） |
| 已有回答的问题只能由教师删除 | `QA-1010` | `QA-1013` |
| 已被采纳的回答只能由教师删除 | `QA-1011` | `QA-1012` |
| 回复必须与父评论同目标 | `QA-1012` | `QA-1017` |
| 被回复的评论不存在 | `QA-4004` | `QA-4003` |
| 课程不存在 | `QA-4003` | `ID-4002`（改用 Identity 的既有编号） |

⚠️ **`QA-1010` / `QA-1011` / `QA-1012` 三个码在新旧方案中含义完全不同**，
对接时务必以本表为准，不要凭记忆沿用旧语义。

前端 `frontend/src/errors.ts` 的文案映射已同步更新。
